meqpy documentation
===================

**meqpy** is a modular Python framework for defining systems and solving
master equations for scanning tunneling microscopy (STM).

Installation
------------

.. code-block:: bash

   pip install git+https://github.com/nanotech-empa/meqpy.git

Quick start
-----------

.. code-block:: python

   import meqpy

   system = meqpy.System()

See the `tutorial notebooks <https://github.com/nanotech-empa/meqpy/tree/main/tutorial>`_
for worked examples.
